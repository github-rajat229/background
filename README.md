# Mountain View Landing Page

A simple, responsive hero layout featuring a background image with centered typography and an overlay container built using pure HTML5 and CSS3.

## Features

* **Centered Flexbox Layout:** Uses modern CSS Flexbox to keep content perfectly centered across all screen sizes.
* **Fluid Typography:** Employs CSS `clamp()` functions to scale headings and body text smoothly between mobile and desktop devices.
* **Full-Screen Background:** Utilizes CSS background cover properties for seamless full-viewport image scaling.
* **Pure HTML & CSS:** Zero external frameworks, dependencies, or JavaScript required.
